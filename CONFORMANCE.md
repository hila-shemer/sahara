# Sahara ISA Conformance Suite — outline

Companion to ISA-SPEC.md v1.0-draft. The suite is handwritten assembly, one
file per group below, self-checking: each test computes a result vector and
compares against expected values baked into the image; mismatch writes the
failing test ID to a well-known address and HALTs, success HALTs with a
magic value in r0. No test depends on the compiler, the OS, or any device
except where that device is the subject.

Rules of construction:

- Every instruction appears in at least one test; every *semantic rule* in
  the spec (each normative sentence that constrains behavior) is owned by a
  named test. New spec sentence → new test, in the same change.
- Tests run under the reference emulator's deterministic trace; each test's
  expected trace hash is recorded. A conforming implementation matches
  results; the reference implementation additionally matches traces.
- Priority order below front-loads what the slice never exercised. Groups
  C1–C4 are the ones with no prior validation anywhere; they are written
  first and reviewed hardest.

## C1 — Traps, nesting, privilege (unexercised by the slice)

- Double fault: fault in handler prologue before state save → dfbase
  reached, bank 1 holds the second fault, bank 0 intact with the first.
- Triple fault: fault at TL=2 halts; verify no sreg was modified.
- TL-lowering pattern: handler saves bank 0 + status, writes TL←0, takes a
  legitimate nested page fault, resolves it, restores, IRETs twice — full
  copy-from-user simulation.
- SYSCALL from user mode; SYSCALL at TL=1 double-faults (spec consequence,
  tested so it stays deliberate).
- PRIV: every supervisor-only operation attempted from user mode (MFSR,
  MTSR, IRET, INVTP, WFI, HALT, cycle write); user read of cycle and fcsr
  succeeds.
- Interrupt masking: IE=0 defers timer/EXTINT but not faults; delivery
  points (between instructions only); epc semantics per cause class
  (faulting pc vs next pc vs the SYSCALL itself).
- Predicated-false instructions cannot fault: false-predicated load to an
  unmapped address, false-predicated SYSCALL, false-predicated illegal
  opcode — all retire with no effect, cycle advances by 1 each.
- IRET at TL=0 (saturation), IRET bank selection at TL=2.

## C2 — MMU runtime remap (the slice's honest gap)

- OS-owned tables: build a mapping with stores, INVTP, access through it.
- Remap under fire: map VA→P1, read; remap VA→P2, INVTP, read — the
  contract whose erosion decision #15 feared. Run with the reference
  emulator's *check mode* that models a translation cache purely to detect
  a missing INVTP (a stale-hit assertion), so the contract is enforced now,
  not when a real cache arrives.
- Path-compression: prefix mismatch faults; regions above 2^64 and 2^100;
  leaf at shift≠0 faults; type-3 entry faults; malformed reserved bits.
- Permissions: R/W/X each individually denied and allowed; U-bit gating in
  user mode; supervisor ignores U but honors R/W/X; PERM_* vs PF_* cause
  codes; baddr correctness on every path including fetch.
- ASID: change ptbase+asid without INVTP (legal), change ptbase alone
  without INVTP (illegal — check-mode assertion fires).
- MMU_EN=0 identity addressing; enable mid-stream; aliasing (two VAs, one
  frame, write through one, read through the other).

## C3 — Atomics (new in v1.0, no prior art in the project)

- CAS success and failure at each width; old value canonicalization;
  width-33 garbage in high bits of expected/new is ignored at w=32.
- Every AMO at every width; signed vs unsigned min/max boundary values.
- Atomicity under interrupts: timer armed to fire "during" an AMO —
  delivery must be before or after, never between read and write (verify
  via trace: no event between the AMO's access pair).
- AMO/CAS to device space traps DEVERR; AMO permission faults report load-
  before-store order.
- ABA-freedom demonstrator (documentation test, not a hardware property):
  64+64 software fat-pointer CAS pattern from the design notes.

## C4 — FP (new in v1.0)

- Each operation at each precision against precomputed IEEE 754 vectors
  (generated by the host's libm at build time, committed as data).
- FMADD single-rounding cases that differ from mul-then-add.
- NaN propagation (canonical quiet NaN), FCMP NaN semantics (false; NV on
  LT/LE only), FMIN/FMAX 754-2019 semantics including ±0.
- fcsr: each rounding mode changes a result that distinguishes it; flags
  sticky; reserved rounding mode traps at next rounding op, not at MTSR.
- FCVT: RTZ always for F→I; saturation and NV for overflow/inf/NaN at
  every (src fmt, dst width) pair; canonicalized integer results; illegal
  format combinations trap.
- Subnormals: no flush-to-zero, exact subnormal arithmetic samples.

## C5 — Base integer semantics

- Canonical form: every W-form op at 32/64 produces sign-extended results,
  including unsigned ops (SHR/UDIV/UREM at w=32 with high garbage in
  inputs).
- Division: by zero (all-ones / dividend), MIN/−1 overflow, at each width.
- MULH/MULHU high halves at each width incl. 128×128→256 upper half.
- mod field: shl 0–63, sxt/zxt each amount class, amount 0 no-op, mod
  ignored when I=1.
- Shifts: counts mod w at each width; SHL vs mod-shl equivalence ≤63.
- Immediates: sign extension at 22 bits; SHORI chaining builds exact
  128-bit constants; LDI/SHORI/LAP field use.
- r31 discard/zero; p0 immutable via PWR and via CMP dst=0.

## C6 — Control flow and predication

- B/JAL displacement arithmetic incl. negative; JALR byte target,
  misalignment traps with baddr=target; ra writing via dst field.
- Predication: all 16 pred-field encodings; polarity; predicated
  everything (stores, branches, IRET squash, CAS squash — no memory
  access on squash, verified by trace).
- PRD/PWR round-trip; handler save/restore pattern from ABI section.

## C7 — Memory and devices

- All load/store widths, sign/zero extension, alignment traps at each
  width, ea composition (base + scaled index + displacement).
- Device ordering rules 1–2 using the reference platform's store-queue
  check mode (the slice's weak-store apparatus, kept as a permanent test
  mode): doorbell-after-stores with and without the release guarantee.
- Device read side effects ordered (input-queue pop).
- Unsupported device access size traps DEVERR.

## C8 — ABI (software conformance, runs against the compiler later)

- >8-argument call forces the stack path (the standing test from the
  design review; with 8 argument registers ordinary code also exercises
  it, but this test pins the layout: [sp + framesize + 16·i]).
- 16-byte slot layout, sp alignment, callee-saved discipline, two-register
  return, k0 never touched by generated code.

## Reference-implementation-only checks

Not ISA conformance, but required of the reference emulator and kept in
the same suite: bit-exact replay of every test's trace; cycle counting (1
per retired incl. squashed, 1 per delivery, WFI jump semantics); WFI
deadlock halts; event-queue determinism under identical input traces.

## Harness requirements

Inherited from the slice's §5 lessons: every test a flag-selected run of
one binary where possible; encoding data (opcode names, field decode) in
the trace decoder generated from encoding.py; symbol sidecar in the image
format from the first test; device-state snapshot diff as a first-class
assertion primitive.
